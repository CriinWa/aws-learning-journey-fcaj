This section lists the blogs published on [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj).

### [Blog 1 - REIMAGINING BINARY ASSET STORAGE IN GAMES WITH LORE](3.1-Blog1/)

This blog explains how Lore changes binary asset storage for game development by fragmenting files, reducing duplication, and making branching far cheaper.

### [Blog 2 - PREVENTING DATA EXFILTRATION ON AWS WITH EGRESS CONTROLS](3.2-Blog2/)

This blog describes how AWS egress controls, data perimeters, and detective services help reduce data leakage risk in both traditional workloads and AI agents.

### [Blog 3 - AUTOMATING ACCOUNT LIFECYCLE MANAGEMENT AND SECURITY RESPONSE WITH AWS DIRECTORY](3.3-Blog3/)

This blog shows how AWS Directory Service Data APIs can automate account lifecycle management and incident response by combining GuardDuty, EventBridge, Step Functions, Systems Manager, and SNS.
